# FontPen

**[FontPen](https://fontpen.com)** is a font editor that runs in your browser. Design fonts, together with others or on your own, and show them off in decks: slide presentations made for type.

It’s made for:

* **beginners** designing their first fonts
* **classrooms**, with a teacher and students working in the same fonts at once
* **anyone** making test fonts and sharing them

Changes are seen live by everyone working on a font or deck, and AI assistants can help too, in FontPen’s chat or over MCP.

FontPen’s source code isn’t public. This repository is where you can tell us about problems and ideas.

## Raise an issue

Found something that doesn’t work, or have an idea that would make FontPen better? [Raise an issue](https://github.com/Lorp/fontpen-public/issues/new).

First, have a quick look through the [open issues](https://github.com/Lorp/fontpen-public/issues), in case someone has already raised it. If they have, add a 👍 or a comment with what you’ve seen: that helps us know what matters most.

### What helps

* **Where:** a link to the page (a font, glyph or deck), if you can share it
* **What happened**, and what you expected instead
* **How to make it happen again**, step by step
* **Your browser and device**, e.g. Safari 26 on a Mac, or Chrome on an iPad
* **A screenshot or short screen recording**, if it’s something you can see

A private font or deck can’t be seen by us through a link alone. Say so, and we’ll ask you if we need to.

## Not here

* **About one font or deck?** Use that font’s or deck’s own chat and issues in FontPen, where its owner and editors will see them.
* **A security problem?** Please don’t post it publicly. Use **Report a vulnerability** on this repository’s [Security](https://github.com/Lorp/fontpen-public/security) tab, so it reaches us privately.
